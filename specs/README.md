# Specs

Test plans that drive generated browser tests. Name each plan after its suite, and keep the
generated specs in [`tests/e2e`](../tests/e2e) in step with it: every spec starts with `// spec:`
and `// seed:` headers naming its plan and seed file. Current plan:
[`myjournal-e2e.md`](myjournal-e2e.md). Run instructions are in
[testing](../docs/development/testing.md).
